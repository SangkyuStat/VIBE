Machine learning gives flexible fits, but scientific questions also need a clear target and an honest measure of uncertainty. We use machine learning tools inside statistical frameworks, so that the flexible parts help with estimation while the answer still means what we want it to mean.

One example is our work on cancer health disparities, where flexible learners help estimate how much of a gap between groups could be closed by changing a modifiable factor.
